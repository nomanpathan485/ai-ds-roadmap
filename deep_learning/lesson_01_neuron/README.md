What is a Neuron?

A biological neuron receives signals and decides whether to fire.

Artificial neurons do something similar.

Input:

Hours Studied = 5
Attendance = 90%

Neuron:

Output = Pass or Fail

Mathematically:

y=f(w1​x1​+w2​x2​+b)

Where:

x = inputs
w = importance (weights)
b = bias
f = activation function
y = output
Intuition of Weights

Suppose:

Hours Studied = 5
Attendance = 90

Weights:

Study Weight = 0.8
Attendance Weight = 0.2

The model is saying:

Studying is more important than attendance.

Learning is simply the process of finding the best weights.
